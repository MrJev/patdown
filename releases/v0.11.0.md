## Plain rule adapters

Adapters can export `loadPatdownRules(override)` and return the usual rules document. The adapter file does not import `effect`. Use this when the app stays on another Effect major. `override` is the `--rules` string, or `null`. The function may return the document or a Promise of it.

`PatdownRuleSourceLive` still works. If a module exports both, the Layer is used.

## patdown doctor

`patdown doctor` loads rules the same way lint does and checks `TYPESAFE_API_KEY` in this process. It does not call the judge. A missing key exits 1. When `CLAUDE_PLUGIN_ROOT` is set, it compares `.claude-plugin/plugin.json` with the installed CLI version.

## Visible skips

Missing rules still skip judging and exit 0. Claude now writes `patdown: skipped write to <path>` on stderr. Pi appends that skip and shows a notice on session start.

## Distribution

Requires Node.js >=22.22.2. Published as `patdown`, `@patdown/rules`, `@patdown/pi`, `@patdown/claude`, and `@patdown/packs`. The same git tag is what consumers pin for the composite action.
