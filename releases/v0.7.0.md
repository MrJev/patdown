## Compose packs with project rules

`AGENTS.PATDOWN.md` can pull in other origins through a leading YAML frontmatter block. One `include` key: a path, or a YAML list. A directory loads every `*.md` except `README.md` (a pack). A markdown file loads that file's `#` rules. Included rules load first, then the local `#` rules.

```
---
include:
  - ./node_modules/@patdown/packs/typescript
  - ./node_modules/@patdown/packs/effect/prefer-effect-fn-for-named-effectful-work.md
---

# Keep secrets out of committed files
globs: **/*

Do not commit API keys or tokens.
```

Duplicate titles fail. Include cycles fail, including a symlink that points back at a file already on the stack. A second `include:` key, unknown frontmatter keys, and an unterminated `---` fail. `--rules` still replaces the walk; if that file has frontmatter includes, they are followed. Pi uses the same loader.

This checkout dogfoods `include: ./packs/typescript`.
