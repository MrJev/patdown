## Claude hook skips redis barrel import

The PreToolUse hook now imports `@effect/platform-node/NodeServices` instead of the package barrel. The barrel re-exports `NodeRedis`, which evaluates `import { SocketTimeoutError } from "redis"` and fails on installs where `redis` is CJS-only. Judging only needs `NodeServices.layer`.

Refresh the Claude plugin after upgrading so the cache is not stuck on `0.10.1` / earlier.

## Distribution

Requires Node.js >=22.22.2. Published as `patdown`, `@patdown/rules`, `@patdown/pi`, `@patdown/claude`, and `@patdown/packs`. The same git tag is what consumers pin for the composite action.
