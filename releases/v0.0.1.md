## Initial release

Patdown is a standalone CLI for checking files against natural-language rules.

- Loads `AGENTS.PATDOWN.md` by walking up from the working directory, or accepts an explicit `--rules` path.
- Each level-one heading defines a rule, with optional `globs:` metadata.
- Evaluates matching files through TypeSafe System One/Jev. An estimated probability of yes strictly above 0.85 counts as a violation.
- Includes `rules` to inspect loaded rules and `ask --noul "question" --state "text"` for direct questions.
- Adds GitHub CI and a tag-triggered release workflow.

## Requirements and distribution

Requires Node.js >=24.18.0 and pnpm 11.8.0 to build from source. The default backend needs `TYPESAFE_API_KEY` for judging; listing rules does not call the API.

This release contains source only. It does not include a standalone executable or npm package. Run `pnpm install` and `pnpm -w patdown -- rules` from the checkout to get started.

The workspace command executes in `apps/patdown`, so relative paths and target globs use that directory.
