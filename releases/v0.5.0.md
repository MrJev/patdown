## File scoping for CI

`--files` (repeatable) and `--files-from` restrict lint to an explicit path list, then intersect with each rule's globs. That is the intended CI path: the workflow lists changed files; patdown decides which rules apply.

```sh
npx patdown --verbose --files-from changed.txt
npx patdown --files src/cli.ts --files README.md
```

Blank lines and `#` comments in `--files-from` are ignored. Paths outside cwd and the usual skipped directories are dropped. An empty selection after filtering still exits `patdown: passed`.

## GitHub Actions output

When `GITHUB_ACTIONS` and `GITHUB_STEP_SUMMARY` are set, patdown writes a job summary and capped `::error` annotations. Opt out with `--no-github`. Annotations are FAIL-only. See [GitHub Actions](../docs/github-actions.md) and the consumer example [examples/github-actions/patdown.yml](../examples/github-actions/patdown.yml).

FAIL judgments can attach line evidence (Choice over per-line candidates, with a chunk fallback for very large files) so annotations get real `line=` / `endLine=` when the judge can locate them.

## Packs

Optional rule bundles live under [`packs/`](../packs/README.md) in the repository:

- [`packs/typescript`](../packs/typescript/) — type-safety crimes and type laundering
- [`packs/effect`](../packs/effect/) — Effect v4 services, schemas, errors, time, HTTP, tests
- [`packs/anti-slop`](../packs/anti-slop/) — fuzzy counterpart to Dillon Mulroy's anti-slop

`--rules <dir>` loads every `*.md` in the directory except `README.md`. Packs are content, not an npm surface: copy a pack into your project or point `--rules` at a checkout.

```sh
npx patdown --rules ./packs/typescript --files-from changed.txt --verbose
```

## Verbose local console

`--verbose` outside GitHub Actions prints one terminal box per rule: directory headers, aligned `✓`/`✗` + shade bar + P(yes) + elapsed, basename last. Quiet mode and GitHub job logs stay one-liners.

```
┌ Do not launder types with casts ─────────────────────── 0✗ / 3
│
├─ apps/patdown/src
│
│  ✓  ▒░░░░░░░░░  0.09   84ms  cli.ts
│  ✓  ▒░░░░░░░░░  0.05   98ms  index.ts
└

patdown: passed (elapsed: 1390ms)
```
