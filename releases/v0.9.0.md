## Claude Code Write/Edit plugin

`@patdown/claude` is a Claude Code plugin that judges `Write` and `Edit` against project `AGENTS.PATDOWN.md` rules before those tools hit disk. Same boundary as `@patdown/pi`: write/edit steering only. Bash and other tools are ignored.

Install from a checkout or marketplace entry, then load with Claude Code:

```sh
pnpm add -D patdown @patdown/rules
claude --plugin-dir ./node_modules/@patdown/claude
# or: /plugin marketplace add tyler-dot-earth/patdown
# then: /plugin install patdown@patdown
```

Needs `TYPESAFE_API_KEY`. Judge errors and a 90s internal deadline deny the write (fail-closed). Reads that leave the workspace through symlinks are rejected. A `/patdown:run-patdown` skill runs the CLI for on-demand tree lint (`pnpm exec patdown`, not bare `npx`).

Best-effort until validated against Claude Code on your machine. See [Claude Code plugin](../docs/claude.md).

## Distribution

Requires Node.js >=22.22.2. Published as `patdown`, `@patdown/rules`, `@patdown/jev`, `@patdown/pi`, `@patdown/claude`, and `@patdown/packs`. The same git tag is what consumers pin for the composite action.
