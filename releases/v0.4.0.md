## Verbose timing and P(yes) bars

`--verbose` now includes elapsed judge time and a ten-cell shade bar for estimated P(yes):

```
FAIL service.ts: explicit-actor (▓▓▓▓▓▓▓▓▒░ estimated P(yes): 0.86; cutoff: >0.85; elapsed: 312ms)
patdown: failed (elapsed: 1840ms)
```

```
yes (░░░░░░░░░░ estimated P(yes): 0.02; cutoff: >0.85; elapsed: 12ms)
```

`▓` is a full tenth, `▒` is a half cell, `░` is empty. Elapsed time is wall time around the judge call, not globbing or file reads. The lint footer is the whole run. Quiet output is unchanged.

## Embedded API

`askPatdownJudge` now returns `{ judgment, elapsedMs }` instead of a bare judgment.

`PatdownLintResult` includes `elapsedMs`. `writeAnswer` takes that duration as a fourth argument. `writeLintOk` and `writeLintFailed` are functions: they accept an optional elapsed-ms argument used by `--verbose`. Custom output layers that assigned `Effect.void` to those members need updating.
