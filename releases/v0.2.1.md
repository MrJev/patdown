## Custom output for embedded callers

- `runPatdownCli` now accepts an optional fourth argument: a `PatdownOutput` Layer. Existing calls retain the default formatter.
- Exports the `PatdownLintResult` type from the CLI package for custom output implementations.
- Adds a complete JSON-output example to the README and tests that verify custom output receives structured judgments and the verbose flag.

```ts
await Effect.runPromise(runPatdownCli(
  undefined, // normal rule-source discovery
  process.argv.slice(2),
  undefined, // default judge
  CustomOutputLive,
))
```

Custom output receives probabilities even when `--verbose` is off and can print, collect, or omit results. Formatting does not change the decision cutoff or exit status.

This is an embedding API, not a new `--format` flag. Help, argument errors, and loading/provider errors still use the existing CLI help/stderr paths. Output-layer effects must handle their own failures.

## Distribution

Source-only GitHub release, with no npm publication or standalone bundle. Requires Node.js >=24.18.0. See the [README example](https://github.com/tyler-dot-earth/patdown/blob/v0.2.1/README.md#custom-output).
