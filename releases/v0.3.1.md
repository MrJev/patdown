## npm packages

The CLI and libraries are on npm:

```
npx patdown --help
pnpm add -D patdown
```

Published names:

- `patdown` — CLI bin and embeddable library
- `@patdown/rules` — rule types and markdown loading
- `@patdown/jev` — TypeSafe/Jev HTTP client used by the default judge

The workspace root package is now `@patdown/workspace` so it does not collide with the unscoped CLI name. `@patdown/oxlint-config` and `@patdown/tsconfig` stay private.

Requires Node.js >=22.22.2. Internal imports use `#src/…` aliases that Node 22 accepts. Releases through v0.2.2 still need Node >=24.18.0.

GitHub tags now publish those three packages when `NPM_TOKEN` is configured. The first npm release was also published from a logged-in local npm account.
